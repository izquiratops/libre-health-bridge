# Agent instructions

## Simulator screenshots

- For PRs that add or change UI elements, include simulator screenshots of the affected screens in the PR description.
- For UI investigation or screenshot capture, follow the [simulator-screenshots skill](https://github.com/izquiratops/skills/blob/28c9de11c31841d18f99548a0785ff3cf9918be7/skills/simulator-screenshots/SKILL.md). If it is not installed, read the source and its relevant linked references.
- Use the synthetic fixtures in `LibreHealthBridge/SimulatorScenarios.swift` for shareable screenshots. Read their launch routing and build guards first; fixtures require a DEBUG simulator build. Inspect each PNG before sharing it.
