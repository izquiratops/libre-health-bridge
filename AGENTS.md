# Agent instructions

## Simulator screenshots

For UI investigation, before-and-after screenshots, or PR image evidence, use the [simulator-screenshots skill](https://github.com/izquiratops/skills/blob/28c9de11c31841d18f99548a0785ff3cf9918be7/skills/simulator-screenshots/SKILL.md). If the skill is not installed, read it and its relevant linked reference files from the source.

For shareable screenshots, use the synthetic fixtures in `LibreHealthBridge/SimulatorScenarios.swift`. Read their launch routing and build guards before launch. They are available only in DEBUG simulator builds. Inspect the captured PNG before sharing it.
